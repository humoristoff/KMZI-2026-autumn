## 1. Задание 1: Алгоритм Дойча

Исследованы все 4 возможные однобитовые функции:
* $f_1(x) = 0$ — постоянная
* $f_2(x) = x$ — сбалансированная
* $f_3(x) = \neg x$ — сбалансированная
* $f_4(x) = 1$ — постоянная

Квантовый алгоритм использует интерференцию и эффект Phase Kickback при целевом кубите в состоянии $|-\rangle$. Состояние управляющего кубита перед измерением:
* Для постоянной функции: $|0\rangle$ с вероятностью 100%.
* Для сбалансированной функции: $|1\rangle$ с вероятностью 100%.

Тип функции определяется строго за **1 обращение к оракулу** (в отличие от классического подхода, требующего 2 вычислений).

## 2. Задание 2: Алгоритм Дойча-Йожи

Для функции $f: \{0,1\}^n \to \{0,1\}$:
* При измерении регистр возвращает строку $|00\dots0\rangle$ с вероятностью 1 тогда и только тогда, когда функция постоянна.
* Если функция сбалансирована, амплитуда состояния $|00\dots0\rangle$ равна $\frac{1}{2^n}\sum_x (-1)^{f(x)} = 0$, поэтому вероятность получить все нули строго равна 0.

## 3. Задания 3–6: Алгоритм Шора (Вариант 7)

### 3.1 Теоретические параметры для $N = 35, a = 2$:
1. Проверка взаимной простоты:
   $$\gcd(2, 35) = 1$$
2. Определение порядка $r$:
   $$2^r \equiv 1 \pmod{35}$$
   Последовательность степеней:
   $$2^1 = 2, \quad 2^2 = 4, \quad 2^3 = 8, \quad 2^4 = 16, \quad 2^5 = 32, \quad 2^6 \equiv 29,$$
   $$2^7 \equiv 23, \quad 2^8 \equiv 11, \quad 2^9 \equiv 22, \quad 2^{10} \equiv 9, \quad 2^{11} \equiv 18, \quad 2^{12} \equiv 1 \pmod{35}$$
   Порядок: **$r = 12$**.

3. Регистры квантовой схемы:
   * Целевой регистр: $n = \lceil \log_2 35 \rceil = 6$ кубитов ($2^6 = 64 > 35$).
   * Управляющий регистр (для фазовой оценки): $m = 2n = 12$ кубитов ($2^{12} = 4096$).

4. Фазовая оценка:
   Измеренное значение $y \approx \frac{s}{r} \cdot 2^m$ для $s \in \{0, \dots, 11\}$.
   Непрерывная дробь восстанавливает порядок $r = 12$ для всех $s$, взаимно простых с $r$. Число таких значений равно $\varphi(12) = 4$ ($s \in \{1, 5, 7, 11\}$).
   Доля успешных измерений:
   $$\frac{\varphi(12)}{12} = \frac{4}{12} = 33.33\%$$

5. Нахождение делителей:
   Так как $r = 12$ чётно, вычисляем:
   $$x = a^{r/2} \bmod N = 2^6 \bmod 35 = 64 \bmod 35 = 29$$
   $$x \not\equiv -1 \pmod{35} \quad (29 \neq 34)$$
   Делители:
   $$d_1 = \gcd(x - 1, N) = \gcd(28, 35) = 7$$
   $$d_2 = \gcd(x + 1, N) = \gcd(30, 35) = 5$$
   $$d_1 \cdot d_2 = 7 \cdot 5 = 35$$

**Результат:** найдены нетривиальные простые множители **7** и **5**!

## 4. Ответы на контрольные вопросы Задания 6

1. **Что произойдёт, если взять простое $N$, например $N = 1009$?**
   У простого числа нет нетривиальных делителей. Значения $\gcd(a^{r/2} \pm 1, N)$ всегда будут тривиальными (равными 1 или самому $N$).
2. **Почему основание с нечётным порядком $r$ не даёт множителей?**
   Факторизация опирается на разложение разности квадратов $a^r - 1 = (a^{r/2} - 1)(a^{r/2} + 1)$. При нечётном $r$ значение $r/2$ не является целым числом, и целочисленное разложение невозможно.
3. **Сколько кубитов понадобится для $N$ длиной 2048 бит?**
   По формуле $3\lceil\log_2 N\rceil$ потребуется:
   $$3 \times 2048 = 6144 \text{ кубитов}$$
