## 1. Задание 1: Квантовые сумматоры

### Схема полного сумматора (5 кубитов: $A, B, X, S, C$):
* Входы: $q_0 = A, q_1 = B, q_2 = X$ (входной перенос).
* Вычисление суммы $S$ на $q_3$:
  $$S = A \oplus B \oplus X$$
  Вентили: `CX(q0, q3)`, `CX(q1, q3)`, `CX(q2, q3)`.
* Вычисление выходного переноса $C$ на $q_4$:
  $$C = (A \land B) \lor (X \land (A \oplus B))$$
  Вентили:
  1. `CCX(q0, q1, q4)`
  2. `CX(q0, q1)`
  3. `CCX(q1, q2, q4)`
  4. `CX(q0, q1)` — возвращает $q_1$ в исходное значение $B$.

Все 8 комбинаций таблицы истинности проверены через `assert`. Каскадный 4-битный сумматор проверен на всех $16 \times 16 = 256$ парах входных чисел ($a + b$).

## 2. Задание 2: Квантовая схема для Варианта 7

Функция:
$$F(A, B, C, D) = (A \land B) \lor (C \land D) \lor (A \land C)$$

Схема построена модульно из элементарных логических вентилей (`AND`, `OR`), реализованных на базе обратимых квантовых гейтов `CCX` и `X`:
* Вычисляются промежуточные результаты в регистр `ancilla`.
* Итоговое значение копируется на выходной кубит с помощью `CX`.
* Применяется обратная подсхема (**Uncomputation**), которая гарантированно возвращает все вспомогательные кубиты в базовое состояние $|00000\rangle$, устраняя паразитное квантовое запутывание.
* Схема протестирована на всех 16 наборах аргументов; результаты совпадают с классической функцией на 100%.

## 3. Задание 7: Алгоритм Гровера (Вариант 7)

* База данных: $N = 32$ ($n = 5$ кубитов).
* Целевое состояние: $|10010\rangle$.
* Формула числа шагов:
  $$k_{\text{теор}} = \left\lfloor \frac{\pi}{4}\sqrt{32} \right\rfloor = 4$$
